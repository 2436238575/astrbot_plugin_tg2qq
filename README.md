# astrbot_plugin_tg2qq

轮询 Telegram 公开频道(通过 `t.me/s/<频道>` 公开预览页,无需 API ID / 登录),把更新合并为一条合并转发消息推送到 QQ 群。

## 工作方式

1. 按配置的间隔(默认 30 分钟)抓取每个频道的公开预览页并解析消息。
2. **首次抓取只记录基线**(当前最大消息 ID),不推送;基线持久化在 `data/plugin_data/astrbot_plugin_tg2qq/baseline.json`,插件重载后不会重复推送旧消息。
3. 之后每轮把 ID 大于基线的消息(单条或多条)按顺序合并为**一条合并转发消息**,推送到白名单 QQ 群;白名单为空时推送到机器人所在的所有群(通过 `get_group_list` 获取)。
4. 向多个群依次推送时,每次发送之间等待"发送间隔"(默认 0.5 秒),避免触发账号风控。
5. 推送失败只记录日志并照常推进基线,不会重复推送。

## 配置项

| 配置项 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `tg_channels` | list | `[]` | 要监听的频道,支持 `@xxx`、`t.me/xxx`、完整链接。留空则不监听也不推送 |
| `poll_interval_minutes` | int | `30` | 轮询间隔(分钟),最小 1 |
| `whitelist_groups` | list | `[]` | QQ 群号白名单,留空推送所有群 |
| `send_interval_seconds` | float | `0.5` | 每次群发送之间的间隔(秒) |
| `skip_push_regex` | list | 空 | 自定义正则:正文命中任意一条的消息整条不推送 |
| `use_content_safety` | bool | `true` | 推送前调用 AstrBot 主配置「内容安全」审核消息文本 |
| `filter_regex` | list | 匹配所有 URL | 推送内容中命中的部分被删除 |
| `exclude_regex` | list | 空 | 正文命中任意一条的消息豁免两个正则(不影响内容安全) |

## 内容安全审核

插件不内置任何敏感词表。开启 `use_content_safety`(默认开)后,每条待推送消息的正文会先经过 **AstrBot 主配置「内容安全」** 的同一套审核(复用 `StrategySelector`),未通过则该条消息不推送(基线照常推进,审核服务异常时放行并记日志)。审核策略在 **AstrBot 主配置 → 内容安全** 中维护:

- **关键词策略**:默认启用,关键词列表默认为空,由你自行填写,每个关键词按正则匹配。
- **百度智能云文本审核**:安装 `baidu-aip` 并填入密钥后启用,覆盖违规全类别且中英文均支持,推荐使用。

主配置的内容安全设置修改后,需在 WebUI 重载本插件才会生效。审核只作用于文本,不检查图片。

## 跳过 / 过滤 / 排除规则

三个正则配置都是**正则列表**:每条列表项一个正则,消息正文命中任意一条即生效;均不区分大小写;列表留空表示禁用;单项写错(无法编译)时记日志并只丢弃该条,不影响其它条目。匹配对象都是**消息正文**(不含时间行和图片)。兼容旧版单条字符串写法(字符串会被当作只有一个条目的列表)。

- **跳过推送正则**(`skip_push_regex`):默认空,按需自行填写;命中的消息不进推送批次,其余消息照常推送;基线照常推进,不会反复重推。
- **内容过滤正则**(`filter_regex`):作用于节点正文、回复、提取出的链接和视频占位行,命中的片段被删除;被清空的行一并移除(因此默认值会把推送里的所有 URL 删干净)。时间行和图片不受影响。
- **排除正则**(`exclude_regex`):豁免开关,正文命中则该条消息**既不跳过也不过滤**(URL 原样保留);内容安全审核不受其豁免。

## 说明与限制

- 仅支持**公开频道**(私有频道没有预览页)。
- 需要 AstrBot 配置了 `aiocqhttp`(OneBot v11,如 NapCat / Lagrange)平台;自动探测第一个该类型平台。
- 频道内容通过合并转发(每条 TG 消息一个节点)展示,节点包含原帖时间(北京时间 UTC+8)、正文、正文内超链接与图片;视频无法从预览页获取,以"视频见原文"链接占位。
- 修改配置后 AstrBot 会热重载插件,立即生效,无需重启。
